# 像素工坊

入口 `像素工坊.html`，連結放在 `Games.html` 的「程式與學習」。直接靜態託管即可使用；不需伺服器上傳或額外套件。`npm run build` 同時產生正式 HTML、CSS、JavaScript、Worker 與圖示。

## 主要原理（目前預設）

把原圖切成等大的正方格，每格把所有像素的 RGB 做平均，再輸出為一個單色像素。原圖背景保留，不做去背、不自動補洞、不預設限成 16 色。透明輸入使用 alpha 加權混色，避免透明像素的 RGB 汙染邊緣。放大匯出採最近鄰，確保每格同色且等大。色票很多時僅顯示前 128 色，不會合併實際輸出的其他顏色。

## 工作流程

1. 上傳、拖放或貼上公開直連 PNG/JPG/WebP/GIF/APNG/BMP/SVG/MP4；保留原始解析度，支援 UHD 3840×2160、DCI 4096×2160 與直向／正方形 4K；超過每邊 8192 px 或 3200 萬像素時明確拒絕，不偷偷縮圖。MP4 用原生播放器選取時間後擷取；GIF/APNG/WebP 使用 ImageDecoder 選幀，瀏覽器無支援或僅單幀時明確降級為第一幀。SVG 使用隔離的 Image 解碼再點陣化。AJPG 若內容是 JPEG 可讀，未知格式會顯示轉檔提示。不編輯或匯出整段動畫。
2. 對比像素邊緣在橫、縱方向的週期，建議格寬、格高與起點。此方法適合近似規則的既有像素圖；一般照片、歪斜格線或模糊圖仍需人工調整。沒有固定像素尺寸。
3. 保留原圖背景，直接按指定格寬、格高與起點切分圖片。
4. 預設每格平均混色；也可選主要色群。原本不等大的色塊與中間色全部按同一格線重新混合。
5. 選擇性填補不接邊界、面積不超過設定的透明洞，或補三面有前景的單格缺口。這不是語意辨識；應人工確認眼睛、髮絲與細小輪廓。
6. 加權 median cut 擷取最多 2–256 色，或映射到 DB16、PICO-8、自訂 HEX 固定色盤。透明不算一色；這些額外限色功能預設不啟用。
7. 畫筆、擦除支援滑鼠與觸控拖曳；最多 24 次修補復原／重做，高解析度會依 96 MiB 歷史快照預算調整次數。選色票選筆色，「替換選色」全圖更換該色。重新套用會清除手動修補。
8. PNG 預設依原圖尺寸匯出，另支援 4K 長邊 3840、原生格數 1× 與 4/8/16/32 倍最近鄰放大及裁除透明留白；獨立 JSON 記錄色盤與最後套用的設定。不是動畫匯出器，可把 PNG 送往動畫或壁紙工具接續製作。

PNG 不含格線、棋盤底紋；預覽縮放與匯出倍率獨立。輸出最多 4096×4096 格，放大後上限 8192 px、16,777,216 像素。運算在 Web Worker，不向網站上傳圖片。

## 匯入限制

圖片 128 MB，MP4 150 MB。連結僅接受無帳密的 HTTP/HTTPS；Fetch 不帶帳號憑證與來源頁網址，30 秒逾時，可取消，依實際內容辨識格式，下載超過上限會停止。需來源允許 CORS；登入頁、相簿分享頁與無跨站許可的網址不能當直連使用，介面提示改下載後上傳。MP4 依瀏覽器編解碼器支援，建議 H.264。替換來源時釋放 Blob URL、影片與動圖解碼器；讀取失敗保留現有素材。

## 驗證

`node scripts/test-pixel.mjs` 驗證格線週期／起點、非方格取樣、透明度、邊界連通去背、洞與缺口、固定色盤、色數上限、裁切與完整處理鏈。

`node scripts/test-pixel-media.mjs` 驗證格式特徵、AJPG 內容辨識、網址限制、HTTP 錯誤、MIME、CORS 錯誤與大小上限。

## 色盤來源

- DawnBringer / DB16：https://lospec.com/palette-list/dawnbringer-16
- PICO-8 / Lexaloffle：https://www.lexaloffle.com/pico-8.php

狐狸為本站以 Canvas 繪製的練習圖，加入不等大的原始色塊與色彩雜訊；色數在執行時實際統計，並非使用者提及的 964 色原圖。

## 4K 記憶體與驗證

`node scripts/test-pixel-4k.mjs` 以真正 3840×2160 RGBA 緩衝區驗證 1px／4px 網格、背景與平均色保留、原圖尺寸／4K 輸出計算、非整除邊緣裁切、DCI／直向／正方形 4K，以及過大輸出拒絕。

精確色數採固定 2 MiB bitset；不限色模式只回傳最多 128 個代表色票，不影響像素資料。JSON 的 paletteContainsAllColors=false 時色票為子集。額外限色在大型圖片採最多 32768 組直方圖，避免記憶體隨獨特色數暴增。原圖尺寸輸出按指定格寬／高整數放大，最後不足一格的邊緣裁至原始邊界；4K 預設選項依圖像比例將最長邊設為 3840。

## 從最高色塊數逐步減少

匯入預設使用原圖可支援的最高密度，不做格線偵測或先降為 4px 格。主畫面的色塊滑桿由長邊格數控制密度，最高逐像素保留（4K UHD 為 8,294,400 格）；向左時使用面積加權 box average 合併色塊，支援小數邊界讓減量平滑，不會從 1px 突跳成 2px 格。數量是真實輸出格數，不是顏色數或匯出畫布像素數。最高密度不超過原圖長邊與 4096 的較小值，不能憑空補出原圖沒有的細節。

滑桿有 140ms 合併輸入，處理時仍可拖曳，只發布最新設定的結果；每次都重新取原圖，不把已經模糊的結果再縮放。新的結果完成前停止匯出，避免匯出舊密度。手動格子改為進階收合，編輯時會切到手動模式；滑桿或「最高細節」可切回。100% 預覽可查看原生格網。
